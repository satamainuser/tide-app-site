# 2026-08-14 Day76 無料トライアルの表記を「1か月」に揃える

アプリの購入画面に「1か月無料」と明記した（Day75）ことで、法務サイトの
「初回30日間は無料」との食い違いが利用者から見える形になった。
App Store Connect のサブスクリプションの無料トライアルは「1か月」で確定しているため、
**App Store 側の設定を正としてサイトを合わせた。**

## タスク1: 特定商取引法に基づく表記の修正

`tokushoho.html` の「販売価格」欄。変更したのは1行のみ。

### 変更前（全文）

```html
      <tr>
        <th>販売価格</th>
        <td>
          潮どきプラス（月額）880円（税込）<br>
          潮どきプラス（年額）5,800円（税込）<br>
          初回30日間は無料。無料期間の終了後、自動的に更新され課金されます。<br>
          解約はApp Storeの購読管理からいつでも可能です。
        </td>
      </tr>
```

### 変更後（全文）

```html
      <tr>
        <th>販売価格</th>
        <td>
          潮どきプラス（月額）880円（税込）<br>
          潮どきプラス（年額）5,800円（税込）<br>
          初回1か月間は無料。無料期間の終了後、自動的に更新され課金されます。<br>
          解約はApp Storeの購読管理からいつでも可能です。
        </td>
      </tr>
```

差分は「初回**30日間**は無料。」→「初回**1か月間**は無料。」の1箇所のみ。
同じ文の後続（自動的に更新され課金される旨、解約は App Store の購読管理から行える旨）、
月額・年額の金額、他のすべての欄は変更していない。

表記の形は、アプリ側で使っている「1か月」（`PERIOD_UNIT_JA` の `MONTH: 'か月'` に由来）に合わせ、
「1ヶ月」「一か月」ではなく「1か月」とした。

## アプリ側との整合

| | 表記 |
|---|---|
| App Store Connect の設定 | 1か月 |
| アプリの購入画面（プランの行） | （1か月無料） |
| アプリの購入画面（課金の条件） | 1か月無料。無料期間の終了後、月額￥880が自動更新で課金されます。いつでも解約できます。 |
| **法務サイトの特商法表記（今回）** | **初回1か月間は無料。無料期間の終了後、自動的に更新され課金されます。** |

購入ボタンの文字は「1ヶ月無料で有料プランを試す」で、こちらは「ヶ」を使っている。
アプリ内での「1か月」との表記ゆれだが、**アプリ側のコードは今回の指示の対象外のため触っていない。**
要判断に挙げる。
