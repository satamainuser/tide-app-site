# 公開ページ一式 作成報告（2026-07-29）

## 概要

審査提出用の公開ページ（GitHub Pages）を、`main` ブランチ直下構成で作成した。
構成方式はホルムズ海峡アプリ（satamainuser.github.io/hormuz/）と同様に、GitHub PagesがmainブランチのルートからServeする方式を採用。ページ自体のデザイン・実装は素のHTML/CSSのみとし、JS・フレームワークは使用していない。

アプリ名は開発中に「(仮称)」から正式名称「潮どき」へ確定。`_config.yml` の `app_name` に集約し、各ページはJekyllのLiquidタグ（`{{ site.app_name }}`）で参照する構成にしているため、名称の反映はこの1箇所の変更のみで完了した。

## 作成したファイル

- `index.html` — アプリ紹介ページ
- `privacy.html` — プライバシーポリシー
- `support.html` — サポートページ（FAQ枠）
- `terms.html` — 利用規約
- `tokushoho.html` — 特定商取引法に基づく表記（個人情報欄はプレースホルダ）
- `assets/css/style.css` — 共通スタイルシート
- `_config.yml` — アプリ名等の設定（Jekyll）
- `README.md` — GitHub Pages公開設定手順

## 各ページの要点

### index.html
アプリ名（潮どき）、潮汐情報の表示・釣果記録という機能概要を紹介。断定的な安全表現（「安全」「必ず釣れる」等）は使用していない。

### privacy.html
釣果記録の位置情報・写真は端末およびユーザー自身のストレージ領域にのみ保存され、開発者サーバーへの送信や第三者提供がないことを明記。アクセス解析・トラッキング不使用を明記。課金はApple/Google経由である旨を記載。問い合わせ先はGitHubリポジトリのIssue（`https://github.com/satamainuser/tide-app-site/issues`）。

### terms.html
必須の免責事項をすべて記載：
- 本アプリは気象庁発表データを表示するものであり、安全性を判定しない
- 海況判断は利用者の責任
- 警報発表時は釣行を控えるなど慎重な行動を促す一般的注意
- 表示データの正確性・完全性を保証しない旨の免責

### support.html
よくある質問の枠を用意。個別の運用詳細（データ取得元の詳細、不具合対応フロー等）は `後日記入` のプレースホルダとした。

### tokushoho.html
特定商取引法に基づく表記の標準項目（販売業者名・所在地・電話番号等）を用意し、個人情報にあたる項目はすべて「後日記入」のプレースホルダとした。存在しない会社名・住所等の事実は創作していない。支払い方法・返品ポリシー等、App Store/Google Play経由の販売に関する一般的な記載のみ実値として記載。

## Git操作

- ブランチをmasterからmainにリネーム（コミット履歴なしの状態で実施のため安全に実施）
- 上記ファイルをコミットし、`origin main` へpush済み
- GitHub Pagesの有効化手順は `README.md` に記載（Settings > Pages > Deploy from a branch > main > /root）。実際のPages有効化（Settings画面での操作）はGitHub上での手動設定が必要なため、この報告時点では未実施。
