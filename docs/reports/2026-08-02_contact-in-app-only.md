## 変更前後の文言

## 変更していない箇所（要判断）

指示の対象が利用規約とプライバシーポリシーの2件だったため、次の3か所は手を付けていない。
記載としては GitHub 受付のまま残っており、規約・ポリシーと食い違う。

- `support.html`（サポート）「不具合のご報告やご質問は、以下のGitHubリポジトリのIssueにて承っております。」
- `_config.yml` の `contact_note`「お問い合わせはGitHubリポジトリのIssueにて承っております。」
- 各ページのフッターの「GitHubリポジトリ」リンク（`site.github_repo`）
  ※ これは問い合わせ窓口ではなくリポジトリへの導線なので、そのままでも矛盾しない
