# 2026-08-13 Day70 App Store 審査 Guideline 1.5 対応（サポートページ / 特商法表記）

App Store 審査で「サポートURLがサポート情報のあるサイトに誘導していない」（Guideline 1.5）を
指摘されたことへの対応。法務サイト（GitHub Pages / satamainuser/tide-app-site）を修正した。

## 事前確認（着手前の適用状況）

| タスク | 着手前の状態 |
|---|---|
| 1. 全ページに noindex | 未適用。5ページすべてに `robots` の meta タグが無かった |
| 2. support.html の作り直し | 未適用。よくある質問が5項目あり、うち4項目が「後日記入」のまま |
| 3. 特商法の「後日記入」置換 | 未適用。7箇所が「後日記入」。お問い合わせ欄は GitHub Issue の URL |
| 4-3. 「当社」→「開発者」 | すでに該当なし。全ページで「当社」「弊社」の使用はゼロで、既に「開発者」表記 |

## タスク1: 全ページに noindex を追加

対象は `index.html` / `terms.html` / `privacy.html` / `support.html` / `tokushoho.html` の5枚。
各ページの `<head>` 内、viewport の meta タグの直後に
`<meta name="robots" content="noindex">` を1行追加した。
公開URLで5ページすべてに1個ずつ含まれていることを確認済み。

## タスク2: support.html の作り直し

### 変更前

- リード文「潮どきのご利用に関するお問い合わせ・よくある質問をまとめています。」
- 見出し「お問い合わせ」＋「アプリ内のこのフォームのみとしており、その他の窓口では承っておりません。」
- 見出し「よくある質問」＋5項目。うち4項目（潮汐データの取得元／動作しない場合／課金の問い合わせ先／
  データ削除の方法）の回答が「後日記入」のプレースホルダー

### 変更後

見出し「よくある質問」と5項目をすべて削除し、以下の4段落に差し替えた。
ヘッダー・ナビ・フッターの枠組み、CSS、URL はいずれも変更していない。

- 質問・不具合の報告は、アプリ内の メニュー →「お問い合わせ」から送る旨
- アプリを起動できない等でフォームを使えない場合の代替窓口として
  `sata17287official@gmail.com`（`mailto:` リンク）
- サブスクリプションの解約・返金・支払い方法の変更は Apple が管理している旨
- 特定商取引法に基づく開示請求も同アドレスで受け付ける旨

解約手順の具体的な階層は、指示どおり記載していない（推測で書いていない）。

## タスク4: サイト全体の点検

1. **プレースホルダーの残存**: `後日記入` / `TODO` / `XXX` / `未定` は全ページで **0件**。
   公開URLでも0件を確認済み。ただし `index.html` のダウンロード欄に
   「現在準備中です。App Store / Google Play での配信開始時に…」、
   ヒーロー部に「開発中・準備ページ」のバッジが残っている（下記「要判断」参照）。
2. **リンク切れ**: サイト内リンクは `/` `/terms.html` `/privacy.html` `/support.html`
   `/tokushoho.html` `/assets/css/style.css` のみで、いずれも実ファイルが存在。
   公開URLで5ページとも HTTP 200。外部リンクはフッターの GitHub リポジトリ
   `https://github.com/satamainuser/tide-app-site`（HTTP 200）のみ。**404 は0件**。
3. **「当社」→「開発者」**: 着手前から「当社」「弊社」の使用はゼロで、既に「開発者」表記に統一済み。
   変更の必要は無かった。
4. **個人情報の露出**: 個人名「新本大貴」は `tokushoho.html` の販売業者欄のみ。
   住所・電話番号の実値はサイト内のどのページにも存在しない（いずれも「請求があれば開示」表記）。
   メールアドレスは support.html と tokushoho.html に掲載しているが、これは指示による窓口の明示。

## 変更していないもの

- 既存のデザイン・配色・ページ構成・CSS
- 各ページのURL

## 公開確認

`https://satamainuser.github.io/tide-app-site/` にデプロイ済み。5ページとも HTTP 200、
noindex あり、プレースホルダー0件、support.html と tokushoho.html の本文が意図どおり反映されていることを
curl で取得して確認した。

## 要判断

- `index.html` に「開発中・準備ページ」バッジと「ダウンロード：現在準備中です」の記載が残っている。
  App Store 審査中のアプリの紹介サイトとしては実態と食い違う可能性があるが、今回の指示範囲外のため
  変更していない。修正の要否を判断いただきたい。
- `tokushoho.html` の「返品・キャンセルについて」は「購入後の返品・返金には対応しておりません。
  App Store / Google Play の返金ポリシーに準じます。」のまま。サポートページに追記した
  「返金は Apple が管理」という記述と表現の粒度が異なるため、統一の要否を判断いただきたい。

## 禁止事項の遵守状況

- 推測で文言を作っていない。指示に値の無かった「動作環境」と冒頭文の扱いは、
  独自判断せず利用者に確認したうえで反映した
- 解約手順の具体的な階層は記載していない
- 価格の数値は指示のとおり（月額880円／年額5,800円／初回30日間無料）で、変更していない
- 秘密情報（`NOTION_TOKEN` 等）をファイル・コミット・報告本文のいずれにも記載していない
